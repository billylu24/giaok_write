# 第一阶段：中文单字手写生成底座

记录日期：2026-10-09。方案建议与已实现内容分开描述；以实验报告为实际状态依据。

## 1. 任务边界

最终应用：中文文本 + 少量个人参考 → 风格一致的手写图像。
第一阶段：先训练/复现通用单字模型；公开训练书写者的样本可用于参考条件，不做目标用户个人微调。

建议底座接口：

```text
目标字符 → 标准字形模板 → 内容编码器 ─┐
公开书写者的其他字 → 风格编码器 ────┼→ 条件扩散 → 单字图像
随机噪声 ─────────────────────────┘
```

书写者 ID 用于构造同一个人的训练配对；推理风格来自参考图片。为了第二阶段接口连续，底座从现在就保留独立风格通路。默认风格可以作为“只输入文字”的演示入口。

第一阶段主要研究：底座见过目标字，但新的参考样本未提供这个字。底座训练也没见过的字符是更难的独立测试，不能混报指标。

## 2. 论文路线

所有来源见 `papers/manifest.json`，本地下载状态见 `papers/download_report.json`。

| 论文 | 借鉴点 | 本阶段优先级 |
|---|---|---|
| FontDiffuser，AAAI 2024 | 多尺度字形条件、条件扩散、风格对比学习；官方训练与采样代码 | 第一版复现基线 |
| CONSTANT，WACV 2026 | 真实中文手写对照；离散风格 token 与局部对比增强；官方 CASIA 权重 | 后续同测试集对照 |
| One-DM，ECCV 2024 | 高频风格提取；中文实验 | 风格分支参考 |
| SLD-Font，2026 预印本 | 内容与风格通路解耦 | 架构改进参考，个人适配留后面 |
| HFH-Font，2024 | 部件条件、蒸馏和超分辨率 | 质量达标后研究 |
| GAR-Font，CVPR 2026 | 全局感知自回归视觉生成 | 替代路线，先阅读 |
| TGC-Diff / DiffBrush | 整行布局与字形风格 | 整行阶段 |
| DiffInk，ICLR 2026 | 轨迹潜空间与扩散 Transformer | 需要笔迹轨迹时再研究 |
| Latent Diffusion，CVPR 2022 | 潜空间扩散基础 | 背景阅读 |

这些工作任务、数据、指标不同，不组成一个可直接比较的总排行榜。FontDiffuser 第一轮权重是字体生成模型；在字体样例上出图，不等于真实个人手写评估通过。

技术勘误：FontDiffuser 官方模型是在 RGB 像素空间工作的扩散模型，并非必需 VAE 的潜空间扩散。其默认分辨率为 96×96。复现时沿用默认配置，再研究 128/256 或潜空间版本。不要把各论文模块直接混装并称为原论文复现。

## 3. 数据准备

起点：CASIA-HWDB1.1 单字数据。官方统计：300 位书写者、3,755 类汉字，约 112 万汉字图像。
官方来源：https://nlpr.ia.ac.cn/databases/handwriting/Offline_database.html

先按官方许可获取数据。未下载真实数据时，官方仓库的示例只能做推理/训练链路验证，不能替代 CASIA。

建议标注表：

```text
sample_id,writer_id,character,image_path,split
```

处理流程：解码字符标签 → 灰度/背景统一 → 保持比例缩放 → 补边 → 为目标字生成标准模板。
保留原图、原始标签及数据来源。避免把个人倾斜、宽窄、重心一律校正掉。

训练、验证、测试按书写者划分；同一个书写者只能属于一个集合。若进行未见字符测试，再额外划分字符集合。根据现有基准的官方划分选择比较设置，不能混用再引用论文指标。

## 4. 训练样本构造

```text
目标内容：标准“湖”
参考：训练书写者 A 的“海、清、明”
监督答案：A 实际写的“湖”
```

建议尽量使参考字与目标字不同，先复现单参考条件，再研究多参考融合。同人参考通过 writer_id 抽取。

第一阶段的数据量是公共训练数据量，和新用户以后提供多少字是两件事。数据增强增加训练组合，不产生新的真实风格信息。

## 5. 实施里程碑

| 里程碑 | 工作 | 验收 |
|---|---|---|
| B0 本地推理基线 | 固定官方代码/权重；中文目标、参考与随机种子；存样例与日志 | 权重校验成功，出图、配置、耗时、记录齐全 |
| B0.1 训练链路验证 | 使用官方极小演示集少量更新；保存模型与损失 | 梯度、优化器、检查点和采样正常；不得解释为泛化能力 |
| B1 真实数据基线 | CASIA 数据转换、书写者划分、目标与参考采样 | 数据统计/重复/缺字检查通过 |
| B2 通用底座训练 | 在公开多书写者数据上训练 FontDiffuser 基线 | 固定验证集与独立测试集可评估 |
| B3 内容改进 | 依据漏笔、形近字等错误加入识别监督或局部监督 | 同配置消融，内容提升且风格无明显退化 |
| B4 对照与交付 | 同测试集对照 CONSTANT，固定推理接口 | 权重、环境、样例、指标和错误报告齐全 |

B0 可以先跑出初步结果。B0/B0.1 完成不代表整个第一阶段 B2 完成。

## 6. 训练原则

先沿用官方模型、损失和采样配置。FontDiffuser 官方有两个训练阶段：基础生成训练，以及借助 SCR 的风格对比训练。这里的“论文 phase 2”与项目的“个人适配第二阶段”不是同一件事。

每次只改一项：内容条件、风格条件、损失、分辨率或采样器。基础训练跑通后再考虑 OCR/内容监督；辅助 OCR 必须独立验证识别能力。复杂汉字不能只看感知指标。

论文完整训练步数、SCR 权重与训练数据范围需按原仓库核对；极小示例集不能据此估算完整收敛时间。

## 7. 评估

- 内容：独立识别器字符准确率，加人工抽检漏笔、多笔、错部件。
- 风格：固定目标换参考；同一参考换目标；新书写者盲评。
- 泛化：目标字不在参考中；训练未见书写者与未见字符分开。
- 工程：采样步数、耗时、峰值显存、模型大小。
- 可重复性：固定 seed、代码提交、依赖版本、数据划分、权重 SHA-256。

少量样例没有可靠的 FID/HWD 统计意义。不使用输入模板相似度冒充字符正确率，也不凭几个生成图宣称达到论文 SOTA。

## 8. 技术栈

Python 3.12 + PyTorch（需支持本机 RTX 5070 的 CUDA 版本）+ 官方 FontDiffuser 模块。
图像：Pillow/OpenCV；配置：JSON/YAML；日志：JSONL + 可选 TensorBoard。
后续数据评估可加入独立中文手写识别器。个人 LoRA、整行生成、服务端 UI 暂不实现。
