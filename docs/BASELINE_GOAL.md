# B0 基线目标与验收

日期：2026-10-09。

## 本轮目标

在本机运行 FontDiffuser 官方预训练权重，生成一批中文单字，保存原始输入、输出、拼图、配置、环境、日志与实测数据。优先达到一个可再次运行的实验闭环。

不纳入本轮验收：完整 CASIA 训练收敛、个人微调、整行生成、全常用字正确率和 SOTA 指标复现。

## 实验设计

1. 官方内容图 + 官方风格图，确认官方示例可执行。
2. 多个中文字符 + 至少两组官方参考图，观察内容保持与风格响应。
3. 同一个样例同一 seed 重跑，记录数值/图像是否一致。
4. 可行时用官方演示集做短训练，证明训练/保存/采样链路可运行；单独报告为 B0.1。

固定参数初始建议：官方 96×96、FP32、DPM-Solver++、20 步、CFG=7.5、seed=123。以实际配置 JSON 为准。
